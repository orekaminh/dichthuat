# 🎧 Phiên Dịch Trực Tiếp (Live Translation)

Ứng dụng web nhận dạng giọng nói và phiên dịch tự động theo thời gian thực (hỗ trợ cả máy tính và điện thoại).

## 🚀 Tính năng chính
- 🎤 **Họp trực tiếp (Micro):** Lắng nghe giọng nói trực tiếp qua micro điện thoại/laptop và dịch tự động.
- 🖥️ **Họp online (Hệ thống):** Thu âm thanh từ tab trình duyệt hoặc cuộc họp Zoom/Teams (chỉ trên máy tính).
- 📱 **Giao diện tối ưu di động:** Thiết kế 2 hàng nút gọn gàng, vừa vặn trên màn hình dọc điện thoại.
- 🌐 **Hỗ trợ đa ngôn ngữ:** Tiếng Anh, Tiếng Trung, Tiếng Nhật, Tiếng Hàn, v.v. sang Tiếng Việt.
- 💾 **Lưu biên bản:** Tải nội dung buổi họp dạng `.txt` song ngữ.

## 📱 Cách dùng trên điện thoại
1. Mở link web bằng **Google Chrome** (Android) hoặc **Safari/Chrome** (iOS).
2. Cấp quyền Micro khi trình duyệt hỏi.
3. Bấm **▶ BẮT ĐẦU NGHE** để dịch trực tiếp.
4. *(Mẹo)* Bấm menu trình duyệt $\rightarrow$ chọn **"Thêm vào màn hình chính"** để dùng như một ứng dụng độc lập.
